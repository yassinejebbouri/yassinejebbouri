### Things I've built

- **[AssetOpsBench inference](https://github.com/yassinejebbouri/AssetOpsBench)**: IBM's maintenance agent took up to nine minutes per answer. We traced it to a chain of up to 63 LLM calls in a row and fired backup copies of stalled ones, which brought the worst case from 559 s to 15.5 s. A 4-bit 3B model also matched the 70B cloud model. *Columbia HPML, advised by IBM Research.*
- **[Adversarial RL](https://github.com/yassinejebbouri/adversarial_rl)**: we trained a 1B model with PPO and GRPO to trick an email assistant into leaking an SSN. It taught itself to pose as a "System Administrator" running an audit.
- **[Multi-Agent Software Architect](https://github.com/yassinejebbouri/MultiAgent_Automated_Software_Architecture)**: five agents with RAG turn a plain-English idea into a full architecture package. An LLM judge still preferred the lazy one-prompt answer, which says a lot about LLM judges.
- **[Steel-Slag SLM](https://github.com/yassinejebbouri/Steel-Slag-SLM)**: *in progress.* A small language model for steel slag research. I built the nightly paper-collection pipeline.
- **[Career Path Navigator](https://github.com/yassinejebbouri/career-path-navigator)**: a knowledge graph of 1,000 AI skills that plans a learning path toward a job. Built for my undergrad capstone.
- **[Q-Trim](https://github.com/yassinejebbouri/Qtrim)**: an RL agent that simplifies quantum circuits, small enough to run on an Android phone.

📄 Co-author of *Do Synthetic Benchmarks Pick the Right Quantum Decoder?*, which tests decoder rankings on real data from Google's Willow chip.
